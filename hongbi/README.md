# 红笔 HONGBI · 刷题题库

把题目，写进红笔里。一个本地优先的刷题网站：上传你的题库文档，选择**合并到公共主题库**供有同样需求的人使用，或**建立自己的私库**。

## 运行方式

无需安装、无需服务器。直接双击 [index.html](index.html) 用浏览器打开即可（推荐 Chrome / Edge）。
数据保存在浏览器 localStorage 中，刷新不丢失。

## 核心功能

1. **上传题库**：支持 JSON / TXT / Markdown / CSV / TSV / PDF / Word(.docx)。文本 ≤ 2MB，PDF·Word ≤ 20MB。
2. **共享确认（强制）**：每次上传解析完成后，都会弹出「共享协议」——
   - 「同意共享」→ 题库合并进**公共主题库**，出现在「题库广场」，任何访问者都可刷题；
   - 「不同意」→ 存入**我的私库**，仅本机可见。
3. **题库广场**：公共主题库（官方精选 + 社区共享），支持搜索与分类筛选。
4. **我的题库**：私库 + 我的贡献，支持预览 / 刷题 / 导出 JSON / 删除。
5. **刷题引擎**：选择题即时判对错，简答题看答案后自评「认识 / 不认识」；顺序随机，进度实时保存。
6. **错题本**：答错/不认识的题自动收录，支持逐题「已掌握」、专项重刷（答对自动移出）。
7. **统计工作台**：题目总数、累计作答、正确率、错题数、最近动态。

## 题库文档格式

### JSON（结构化，推荐）
```json
{
  "title": "题库标题",
  "desc": "描述",
  "category": "分类",
  "questions": [
    {
      "q": "题目",
      "options": ["选项A", "选项B", "选项C", "选项D"],
      "answer": "选项A（也可写 A）",
      "explanation": "解析"
    },
    { "q": "简答题干", "answer": "参考答案", "explanation": "解析" }
  ]
}
```
也支持纯数组 `[{...}]`；字段别名：`question/题目/题干`、`ans/答案`、`解析`、`选项`。

### TXT / Markdown（自动识别）
```
1. 题目
A. 选项A
B. 选项B
C. 选项C
D. 选项D
答案：A
解析：说明文字

2. 简答题干
答案：参考答案
```
也支持：`Q：xxx / A：xxx` 同行写法、`题目|答案` 单行分隔、以及「奇数行题目 / 偶数行答案」的配对格式。

### CSV / TSV
表头：`题目,答案,选项,解析`（选项之间用 `|` 分隔）；无表头则按 题目,答案,选项,解析 的列序。

> 提示：文件请保存为 **UTF-8** 编码，避免中文乱码。

### PDF / Word
- 上传 PDF 或 .docx 时会自动提取文字，再按上面的文本格式解析（首次使用需联网加载在线解析库）。
- **扫描版 / 图片型 PDF** 没有文字层，无法提取，请转为 TXT 或 JSON 后上传。
- 复杂排版（分栏、表格）可能导致题目错位，建议优先使用 TXT / JSON。

> 解析技巧：如果题目和选项写在同一行（如 `题目 A.甲 B.乙 C.丙 D.丁`）或使用全角点（`A．甲`），解析器也能自动拆出选项。

## 技术说明

- 纯前端实现（原生 HTML/CSS/JS，无构建步骤、无第三方依赖），方便直接部署到任意静态托管（GitHub Pages、Vercel、Nginx 等）。
- 当前「公共主题库」为本地模拟：共享数据只存在本机浏览器。**真正让不同用户之间互通，需要加一个后端**，推荐方案：
  1. Node.js + Express/Koa + SQLite/Postgres，提供题库 CRUD 与共享合并 API；
  2. 或 Serverless（Supabase / Firebase）做认证 + 题库表 + 贡献审核；
  3. 上传解析逻辑（`js/parser.js`）可直接复用，前端只需把「同意共享」的提交改为 POST 到服务端。
- 设计：纸质试卷 × 红笔批改风格，字体 Noto Serif SC / ZCOOL XiaoWei / JetBrains Mono（CDN 加载，离线时自动回退系统字体）。
