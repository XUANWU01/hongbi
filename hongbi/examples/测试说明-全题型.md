配套测试题库：[测试文档-全题型题库.txt](测试文档-全题型题库.txt)（18 题，覆盖所有题型与格式变体）。
使用方式：上传 → 选择「不同意，建立我的私库」→ 刷题验证。

## 用例清单与预期结果

### 第 1 部分：单选题（1-7 题）

| 题号 | 测试点 | 预期 |
| --- | --- | --- |
| 1 | 同行选项 `A.xx B.xx C.xx D.xx` + `正确答案：` | 选择题，4 选项，答案=C（显示器） |
| 2 | 全角点选项 `A．1024` + `答案：A` | 选择题，答案=A（1024） |
| 3 | 顿号选项 `A、9` + `【答案】C` | 选择题，答案=C（11） |
| 4 | `参考答案：B` | 选择题，答案=B（80） |
| 5 | 答案在题干行尾 `答案是：D` | 选择题，答案=D（DNS），题干不含答案文字 |
| 6 | `答案是：B` 独立行 | 选择题，答案=B（2） |
| 7 | 题干含英文 `core-site.xml`（e. 片段） | 简答题（不误拆选项），有答案 |

### 第 2 部分：多选题（8-12 题）

| 题号 | 测试点 | 预期 |
| --- | --- | --- |
| 8 | 连续字母 `ACD` | 多选题，可多选，答案=ACD（显示器/打印机/音箱） |

| 12 | 空格分隔 `A C D` | 多选题，答案=ACD（硬盘/U盘/光盘） |

## 扩展格式测试（单独文件）

以下格式需单独文件上传测试（与其他题混排会被状态机合并）：

1. **奇偶行配对**（奇数行题目、偶数行答案）：
```
中国的首都是哪个城市？
北京
Python 中定义函数的关键字是？
def
```
预期：2 题，每题答案取自下一行。

2. **单行分隔**（题目|答案）：
```
中国的首都是____|北京
1GB等于多少MB|1024
```
预期：2 题，按 | 拆分。

3. **Q/A 同行**：
```
Q：中国的首都是？ A：北京
Q：1+1=？ A：2
```
预期：2 题。

4. **JSON 结构**（见 `示例题库-前端.json`）：字段 `q/options/answer/explanation`，答案可写选项文本或字母。

## 刷题交互测试要点

1. 单选：点选项即时判对（蓝=对/红=错），快捷键 A-D。
2. 多选：可点选多项（高亮），显示「已选 N 项」，提交后全对才得分；答案区显示字母（如 B、D、E）。
3. 简答/填空：输入框作答 → 提交 → 自动判分提示（要点命中率）→ 对照参考答案 → 自评。
4. 判断题：走单选交互（正确/错误）。
5. 答错自动进错题本（红点 +1）；错题本「专项重刷」答对自动移除；错题回顾显示当时的作答。
6. 上传预览：显示题数、格式、前 3 题样例、警告（折叠）。
