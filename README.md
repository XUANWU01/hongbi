# 红笔 HONGBI · 服务器化刷题平台

上传题库文档（Word / PDF / TXT / JSON 等）→ 服务器解析 → 共享审核 → 刷题、错题本、收藏、统计云端同步。支持多用户、跨设备进度、四套主题。

**代码位于 [`hongbi/`](hongbi/) 目录**，包含完整前端与后端（Node.js + Express + SQLite，零原生编译）。

## 快速开始

```bash
cd hongbi
npm install
node server/server.js
```

访问 <http://localhost:8712>

详细文档见 [hongbi/README.md](hongbi/README.md) 与 [设计文档](hongbi/docs/)。
